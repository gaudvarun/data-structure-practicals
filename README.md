## ⚙️ Getting Started & Compilation

Clone this repository to your local machine and compile individual practicals using standard toolchains:

### 🛠️ Compiling C Practicals (Data Structures)
```bash
cd data_structures
gcc practical_6.c -o practical_6
./practical_6
```

### ☕ Compiling Java Practicals (OOP)
```bash
cd oop_java
javac practical_11.java
java practical_11
```
