## ⚙️ Compilation & Execution Guide

Ensure you have a standard C compiler (such as `gcc` or `clang`) installed on your system.

### 1️⃣ Clone or Download
```bash
git clone https://github.com/your-username/data-structures-lab.git
cd data-structures-lab
```

### 2️⃣ Compile and Run any Practical
Replace `practical_X.c` with your desired practical file:
```bash
# Compilation
gcc practical_8.c -o practical_8

# Execution (Linux / macOS / WSL)
./practical_8

# Execution (Windows CMD / PowerShell)
.\practical_8.exe
```
