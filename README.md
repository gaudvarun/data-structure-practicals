# 🚀 Data Structures Laboratory (DS) - C Practicals

Welcome to the Data Structures Laboratory repository. This repository contains complete C implementations covering searching, sorting, stack-based expressions, queues, singly linked lists, polynomial addition, circular doubly linked lists, and graph traversal algorithms.

---

## 📂 Repository Structure & Index

| Practical | File Name | Description |
| :---: | :--- | :--- |
| **01** | [`practical_1.c`](practical_1.c) | Searching Techniques (Linear Search & Binary Search with Best/Worst case analysis) |
| **02** | [`practical_2.c`](practical_2.c) | Bubble Sort with Performance Metrics (Passes, Comparisons, Swaps, Early Termination) |
| **03** | [`practical_3.c`](practical_3.c) | Selection Sort (for strings/cities) & Merge Sort (for delivery days with splitting/merging) |
| **04** | [`practical_4.c`](practical_4.c) | Infix to Postfix Conversion & Postfix Expression Evaluation using Stacks |
| **05** | [`practical_5.c`](practical_5.c) | Circular Queue Implementation (Railway Ticket Counter Simulation) |
| **06** | [`practical_6.c`](practical_6.c) | Singly Linked List Operations (Insertion & Deletion at Beginning, Position, End) |
| **07** | [`practical_7.c`](practical_7.c) | Polynomial Addition using Singly Linked Lists |
| **08** | [`practical_8.c`](practical_8.c) | Circular Doubly Linked List Operations (Standard CDLL Implementation) |
| **09** | [`practical_9.c`](practical_9.c) | Circular Doubly Linked List Advanced Operations & Menu Drive |
| **10** | [`practical_10.c`](practical_10.c) | Graph Traversals using Breadth-First Search (BFS) and Depth-First Search (DFS) |

---

## 🛠️ Compilation and Execution Guide

To compile and run any of the practical programs via the terminal:

```bash
# Compile the specific practical file
gcc practical_6.c -o practical_6

# Run the compiled binary
./practical_6
```
